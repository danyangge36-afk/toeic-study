# TOEIC 高分学习助手

一个**零依赖、纯本地**的托业（TOEIC L&R）备考软件：双击 `index.html` 即可使用，无需安装、无需联网（链接类资料除外）。

## 🚀 如何使用

1. 用 Chrome / Edge / Safari 打开本文件夹中的 `index.html`（双击即可）
2. 首页设置**考试日期**和**目标分数**，开始倒计时
3. 按首页的「30 天冲刺计划」（备考指南页）每天训练

> 建议固定用同一个浏览器打开，学习记录保存在浏览器本地（localStorage），换浏览器或换文件路径会另存一份。

## 📦 功能

| 模块 | 内容 |
|---|---|
| 📖 词汇 | 222 个托业高频词（10 大商务场景 + 高频短语），闪卡 + 测验双模式，**SRS 间隔重复算法**自动安排复习 |
| 🎧 听力 | Part 1-4 真题式练习，使用浏览器 TTS 朗读（可在首页调速/换音色，推荐 Samantha）；Part 3/4 答完 3 题才显示原文 |
| 📖 阅读 | Part 5（30 题语法，带考点标签）/ Part 6（4 篇长文填空）/ Part 7（单篇 + 双篇） |
| ⏱️ 模拟考试 | 快速模考（听 22 + 读 26，45 分钟）/ 听力专项 / 阅读专项，严格计时，自动出估算分和错题回顾 |
| ❌ 错题本 | 做错自动收录，重练答对自动移出 |
| 📌 备考指南 | 考试结构、分数段、日本报考信息、各 Part 高分策略、30 天计划、精选资源（IIBC 官方、公式問題集、金のフレーズ、abceed 等） |

## 🇯🇵 日本考生备注

- 报名/日程/受験料以官方为准：https://www.iibc-global.org/toeic/
- 公开考试全年约 10 次（多为周日），受験料约 7,810 日元
- 搭配官方『公式TOEIC Listening & Reading 問題集』纸质套题训练涂卡节奏效果最佳

## 🔧 如何扩充内容

- 加单词：编辑 `data_vocab.js`，往对应分类的 `words` 数组里加 `{ w, p, zh, ex }`
- 加题目：编辑 `data_questions.js`（P1-P7 各数组格式一目了然，照抄一条改内容即可）
- 改样式：`index.html` 顶部 `<style>`

## 💡 托业 ≠ 托福

TOEIC（990 分制）考职场商务英语，是日本求职/晋升的主流英语成绩；TOEFL（120 分制）考学术英语、用于留学。本软件针对托业；如需托福版可在此基础上扩展题库与模块。
